# HackerProblems

A collection of standalone Go solutions to programming challenges. Each problem is in its own directory and reads input from standard input.

## Solutions

- `hk1`: Counts the words represented by a CamelCase string, using uppercase letters to mark the start of additional words.
- `hk2`: Applies a Caesar cipher shift to alphabetic characters, preserving their case and leaving other characters unchanged.

Each solution prints its result to standard output.
